# Daywell workspace

Daywell is a private lifestyle tracker for Android and desktop browsers.

**Start with the [complete Daywell README](daywell/README.md).** It explains how to use, run, understand, modify, test, and deploy the app, including guidance for AI coding tools.

- Application and Git repository: `daywell/`
- Live app: https://daywell-lifestyle.wintryquail64.chatgpt.site (approved sign-in required)
- Local development helpers: `.tools/` (machine-specific; not application source)

Run application commands from `daywell/`, not this workspace root:

```sh
cd daywell
```

If you open this workspace in Codex or another AI tool, ask it to read `daywell/README.md` before making changes. The source repository begins inside `daywell/`; the root README and `.tools/` directory are outside that repository
